CREATE A STUDENT LOGIN

Each click makes one login: an adjective starting with your letter, an animal, and a two-digit number that starts with the period. For example, L and period 3 give names like luckyotter37. Each student gets a random 4-digit PIN, and is grouped under their period in Class results.

HOW PUBLISHING WORKS

Edit below (your draft autosaves in this browser). When you're happy, press Export to download questions.json. Replace that file in the site folder with it and push. Students get the new set on their next page load.

ADD QUESTIONS

Generated questions come with a figure: two congruent triangles with three pairs of markings. Answers ignore capitals, spaces and symbols, so QMR, qmr and △QMR all count. In question text, [[AB]] shows as segment AB with a bar over it. Editing the text keeps the figure. Questions you add yourself have no figure.
